# Стоматология «众信口腔门诊部» (Хэйхэ)

Материалы стоматологической клиники.

| Папка | Что внутри |
|---|---|
| `документы/` | Бизнес-лицензия и медицинская лицензия |
| `логотип/` | Логотип клиники |
| `фото/` | Фото КТ-снимка и руководителя |
| `для рилс 1/` | Фото и видео для рилс (фасад, ресепшн, кабинет, КТ, врач) |
| `до и после/` | Фото и видео результатов лечения «до и после» |
| `скрин сайт стом/` | Скриншоты сайтов стоматологий |
